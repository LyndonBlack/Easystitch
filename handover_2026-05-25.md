### Known issue — House chimney (8-colour mode)
The chimney corner at the top-right where the wrap path turns 90° does not split into its own selectable segment. Root cause: the corner is intra-object (not on a Satin boundary), and the DP-simplified wrap-path polyline passes >50px from the nearest endpoint node of the side edge (edge10). All tolerance-based approaches fail because the distance is genuinely too large.

Three approaches tried and set aside:
1. **Promoted-junction second pass** — node becomes degree-3 junction from OTHER edges but the specific edge1 wrap path is >50px away
2. **Endpoint-margin physical-location bypass** — same root cause, node is genuinely far from the polyline
3. **Self-near-intersection** (Phase C.10, archived/active but commented out) — catches corner at min_gap ≤3 but creates false positives on gentle curves

All backend code for these approaches remains in place with default values that match the working state. The diagnostic UI sliders/checkboxes are HTML-commented-out (`<!-- ... -->`) but can be uncommented for future experimentation.
